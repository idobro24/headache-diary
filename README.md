# Тише

Бережный дневник головной боли: помогает быстро записать приступ, поддержать себя, пока болит, и увидеть закономерности, которые полезно показать неврологу.

**Открыть приложение:** https://idobro24.github.io/headache-diary/

## Что умеет приложение 

### Запись приступа
- Одна большая кнопка «Началось»: время начала сохраняется сразу, остальное можно дополнить позже, когда станет легче. 
- Сила боли по шкале из четырёх уровней: лёгкая, умеренная, сильная, невыносимая.
- Характер и место боли, сопутствующие симптомы (тошнота, свето- и звукобоязнь, аура) и возможные триггеры.
- Лекарства с дозой и временем приёма, подсказки по ранее использованным препаратам.
- При завершении приступа приложение спрашивает, помогло ли лекарство.
- Прошлые приступы можно добавить задним числом, любую запись можно отредактировать или удалить.

### Помощь во время приступа
- Фразы поддержки, которые плавно сменяют друг друга, в том числе личные, основанные на собственной истории («Твой прошлый приступ закончился через 4 часа»).
- Дыхательная гимнастика: круг, который растёт на вдохе (4 секунды) и сжимается на выдохе (6 секунд).
- Успокаивающие звуки: дождь, дождь в лесу, камин, белый, мягкий и «водопадный» шум. Все звуки синтезируются прямо в браузере и работают без интернета.
- Чек-лист самопомощи и памятка о тревожных симптомах, при которых нужна срочная медицинская помощь.
- Режим без анимации для дней, когда любое движение на экране неприятно.

### История и статистика
- Календарь месяца: цвет дня показывает силу боли, дни без записей считаются днями без боли.
- Статистика месяца: дни с болью и сравнение с прошлым месяцем, средняя длительность и сила, частые триггеры, эффективность лекарств.
- Счётчик дней с обезболивающими за 30 дней с мягким предупреждением о риске лекарственно-индуцированной головной боли.

### Данные
- Отчёт для врача за 30 дней, 3 или 6 месяцев: можно показать на экране, отправить файлом или распечатать.
- Резервная копия в файл и восстановление из неё. При восстановлении записи объединяются, дубликаты не создаются.

## Приватность

Все данные хранятся только на устройстве пользователя. У приложения нет сервера, регистрации, аналитики и рекламы: записи о здоровье никуда не отправляются.

## Технологии

- **HTML, CSS и JavaScript** без фреймворков и сборщиков.
- **PWA (Progressive Web App)**: устанавливается на экран телефона и открывается как обычное приложение на Android и iOS.
- **Service Worker**: офлайн-режим со стратегией «сначала сеть, при её отсутствии сохранённая копия».
- **localStorage**: хранение записей на устройстве.
- **Web Audio API**: генерация звуков дождя, камина и шумов без аудиофайлов.
- **Web Share API**: отправка резервной копии и отчёта через системное меню «Поделиться».
- **GitHub Pages**: бесплатный хостинг.

## Как установить на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть ссылку в Chrome → меню ⋮ → «Установить приложение».

## Структура проекта

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка всех экранов |
| `style.css` | Оформление: оливковая тема, адаптация под телефоны, режим печати |
| `storage.js` | Работа с данными на устройстве |
| `logger.js` | Запись, редактирование и завершение приступа, главный экран |
| `help.js` | Экран помощи: фразы, дыхание, звуки, чек-лист |
| `history.js` | Календарь, список приступов и статистика |
| `report.js` | Отчёт для врача, резервная копия и восстановление |
| `app.js` | Навигация и запуск приложения |
| `sw.js` | Офлайн-режим |
| `manifest.json` | Название, иконки и настройки установки |

## Важно

Приложение помогает вести дневник и замечать закономерности, но не ставит диагноз и не заменяет консультацию врача.
